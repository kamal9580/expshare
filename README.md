##EXPSHARE

Authentication:

User registration and login
JWT-based authentication
Secure password hashing with bcrypt
Submission Management:

Create new interview experience submissions
View all submissions with pagination
Detailed view of individual submissions
User-friendly forms with validation
User Interface:

Clean and modern design with Tailwind CSS
Responsive layout for all screen sizes
Interactive components with loading states
Form validation and error handling
Backend API:

RESTful endpoints for CRUD operations
MongoDB integration with Mongoose
JWT middleware for protected routes
Pagination support
To use the application:

Start MongoDB locally on port 27017
Run the server: npm run server
Run the frontend: npm run dev
Register a new account or login
Share your interview experiences
View and manage your submissions
